## English

This repository only hosts release binaries for **Maab**, an Islamic companion app (Quran, Azkar, prayer times, tasbeeh, hifz tracking). No source code lives here.

Grab the latest APK from the **[Releases](../../releases/latest)** page and install it on your Android device.
